    Inteligência

    Jornada do Interessado

    Sequência de seis etapas — primeiro contato, manifestação de interesse, atualização de informações, confirmação, conversão em inscrição, pós-inscrição — que estrutura a coleta progressiva de dados definida no Projeto 11 e operacionalizada pelo Manual do Formulário de Manifestação de Interesse.

    1ª aparição: Projeto 11 — Sistema de Inteligência Pré-Inscrição

    Inteligência

    Coleta Progressiva

    Princípio segundo o qual nenhum campo de dado é solicitado de uma só vez — a coleta acontece em camadas ao longo da Jornada do Interessado, reduzindo fricção e respeitando o tempo de decisão de cada pessoa.

    1ª aparição: Projeto 11 — Sistema de Inteligência Pré-Inscrição

    Tecnologia

    Fonte Única de Dados

    Princípio segundo o qual cada dado tem exatamente uma origem primária rastreável, mesmo quando aparece em múltiplos painéis ou sistemas — evita duplicação de coleta e inconsistência entre painéis.

    1ª aparição: Projeto 11 — Sistema de Inteligência Pré-Inscrição

    Tecnologia

    Pessoa (entidade central do CRM)

    Unidade central do CRM — uma pessoa pode acumular múltiplos papéis ao longo do tempo (atleta, treinador, voluntário etc.) sem gerar cadastros duplicados; o perfil funcional é sempre um atributo da Pessoa, nunca o contrário.

    1ª aparição: Manual — CRM

    Tecnologia

    Catálogo de KPIs

    Lista formal de indicadores do Dashboard Executivo, cada um com definição, objetivo, interpretação, frequência, responsável e decisão associada — nenhum indicador existe sem vínculo a uma decisão real.

    1ª aparição: Manual — Dashboard Executivo

    Tecnologia

    Storytelling Executivo

    Sequência fixa de apresentação de dados a um gestor: o que aconteceu → por que aconteceu → quais impactos existem → quais decisões são recomendadas.

    1ª aparição: Manual — Dashboard Executivo

    Comunicação

    Honestidade Estatística

    Conjunto de regras técnicas permanentes para qualquer visualização de dado público: gráficos sem distorção de eixo, mapas com proporção fiel, comparações sempre rotuladas, percentuais sempre com base declarada.

    1ª aparição: Manual — Stories Baseados em Dados

    Comunicação

    Sistema de Social Proof

    Uso de dados reais e verificáveis da comunidade (ex.: número de boxes ou estados já com interesse manifestado) para gerar pertencimento coletivo genuíno, sem exagero ou número artificial — base filosófica do Manual dos Stories Baseados em Dados.

    1ª aparição: Projeto 10 — Sistema de Lançamento e Mobilização
